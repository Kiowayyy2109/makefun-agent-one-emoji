## The emoji

> 🧭

An AI agent is not a chatbot that waits to be asked. It is given a goal
and finds its own way there — orienting itself, choosing a direction,
correcting course as it goes. The compass is that character in one
glyph: autonomous navigation toward a goal. It reads instantly at small
size, it is a familiar shape, and it is not the obvious robot or smiley
half the field will send.

## How to run

```sh
python3 main.py
```

This writes the emoji (one glyph, 2 characters including the trailing
newline) to `/output/entry.txt`. Python 3.13, standard library only, no
network access, deterministic.
